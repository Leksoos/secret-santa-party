# 🎅 Тайный Санта: Jackbox Party Edition

Интерактивное веб-приложение и Telegram Mini App для проведения праздничного вечера Тайного Санты в стиле комедийных игр **Jackbox Games**.

В отличие от стандартных генераторов пар, сервис превращает вручение подарков в захватывающее вечернее шоу на общем телевизоре или проекторе.

---

## ✨ Ключевые возможности

1. **Режим «Jackbox Party» на большом экране (ТВ / Проектор)**:
   - Открывается по 4-значному коду комнаты (например, `SANTA-2026`).
   - Колесо судьбы / драматический барабан: выбор следующего получателя.
   - Секретная юмористическая загадка от Санты.
   - Живое голосование на смартфонах гостей: *«Кто Санта?»* с подсчетом очков.
   - Фото-бэкстейдж в стиле Polaroid: показ мемных фото процесса покупки и упаковки подарка.
   - Торжественное раскрытие Санты под фанфары и салют из конфетти!

2. **Мобильный пульт-контроллер (Смартфоны / Telegram Mini App)**:
   - Вход по ссылке, коду или QR-коду за 1 клик.
   - Саундборд живых реакций (👏 Аплодисменты, 🤣 Смех, 🔔 Джингл, 😱 Шок, 🦗 Сверчки, 🥂 Тост, ❄️ Снежок). Тапы мгновенно озвучиваются и взлетают на экране ТВ.
   - Кнопки голосования и отгадывания Санты.
   - Управление шагами для организатора.

3. **Личный кабинет Санты (До вечеринки)**:
   - Анимированный сургучный конверт с секретным подопечным.
   - Вишлист и **Анти-вишлист** (что категорически не дарить).
   - Загрузка до 3 секретных фоток бэкстейджа с остроумными подписями.

4. **Аудио-визуальный движок**:
   - Встроенный Web Audio синтезатор (рождественские колокольчики, джинглы, звуки рулетки, затвора камеры, фанфар и аплодисментов) — работает без задержек и внешних файлов.
   - Canvas-анимация падающего мягкого снега.
   - Эффекты салюта конфетти (`canvas-confetti`).

## 🚀 Быстрый запуск

### 1. Установка и запуск в режиме разработки

В терминале перейдите в папку проекта и запустите:

```bash
cd /Users/leksoos/secret-santa-party
npm run dev
```

Команда одновременно запустит:
- **Backend (Express + Socket.IO)**: `http://localhost:3001`
- **Frontend (Vite + React)**: `http://localhost:5173`

Откройте в браузере:
👉 **[http://localhost:5173](http://localhost:5173)**

---

### 2. Мгновенный тест на предзаполненной демо-комнате

В проект уже встроена готовая уютная комната с 4 персонажами (Олег, Лена, Дима, Аня), заполненными вишлистами и загруженным фото-бэкстейджем:

- **Код комнаты**: `SANTA-2026`
- Прямая ссылка: `http://localhost:5173/?code=SANTA-2026`

Попробуйте:
1. Открыть вкладку **«Экран ТВ»** и нажать **«НАЧАТЬ ВЕЧЕР ДАРЕНИЯ 🚀»**.
2. В соседней вкладке или окне открыть вкладку **«Пульт»** и тапать кнопки саундборда — смайлики и звуки синхронно отобразятся на экране ТВ!

---

### 3. Запуск тестов

Для проверки алгоритма жеребьевки и стейт-машины игры:

```bash
npm test
```

## 📱 Запуск в Telegram Mini App

Приложение полностью адаптировано под работу внутри Telegram (`@telegram-apps/sdk-react` и `Telegram.WebApp`):
- Поддерживает тактильный виброотклик (Haptic Feedback) на смартфонах при тапах по кнопкам реакций и голосовании.
- Автоматически подтягивает имя и ник пользователя из Telegram.
- Для привязки к Telegram-боту укажите URL вашего развернутого приложения в BotFather (`/newapp` или в меню WebApp).
